Data Tambahan
Catatan model: path loss otomatis pakai Okumura-Hata (<1500MHz), COST231-Hata (1500-2300MHz), atau 3GPP TR 38.901 UMa (≥2300MHz). Obstruksi bangunan dihitung sebagai difraksi knife-edge dominan (aproksimasi ITU-R P.526). RSRQ/SINR diestimasi dari RSRP + margin interferensi/noise (bukan pengganti survei RF penuh).

Cara kerja: RSRP mentah tiap site di-smooth dulu dgn L3 filter (F_n=(1-a)F_n-1+a·M_n, a=1/2^(k/4)), lalu handover baru dieksekusi jika Event A3 (RSRP neighbour − Hys > RSRP serving + Offset) bertahan terus-menerus selama Time-to-Trigger — persis parameter yang di-tuning RF engineer di OSS (Hysteresis/A3Offset/TimeToTrigger/FilterCoefficient), bukan sekadar "site terkuat langsung menang".
